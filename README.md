# Erabita English prototype

An English-language editorial prototype for erabita.online. It includes a responsive home page, category filters, search, an about page and nine English sample articles.

## Local preview

Serve the directory with any static file server and open `index.html`.

## Domain

The custom domain is intentionally not attached during this prototype phase. After review, point `erabita.online` to GitHub Pages and add a `CNAME` file containing `erabita.online`.
